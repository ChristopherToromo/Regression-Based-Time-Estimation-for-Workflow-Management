# Regression-Based-Time-Estimation-for-Workflow-Management
Regression-Based Time Estimation for Workflow Management: A Comparative Model Analysis

This test project utilizes machine learning regression models for predicting the completion of tasks in the workflow operation process. The data set used in the project consisted of 2,500 workflow tasks, with features including the level of priority, department, employee workload, and approval requirements for the tasks. The project used multiple regression models for predicting the completion of the tasks in the workflow operations process.

**Analysis:**

* The project used data preprocessing, feature engineering (creation of 50+ features), data leakage, and model comparison for the workflow operations process. The project used seven regression models, including Linear Regression, Random Forest, and Gradient Boosting, for predicting the completion of the tasks in the workflow operations process. The models used in the project performed well, with the models having an R² value greater than 0.99. The results obtained from the project indicated that the estimated time, employee workload, and approval level are good predictors for the completion of the tasks in the workflow operations process.
